# Contributing

Thanks for your interest in NetSpeed!

1. Open an issue describing a bug or idea. Include the Android version, phone model, and an image or reproduction steps when useful.
2. Keep code changes focused on the app's one goal: displaying current network transfer speed.
3. Work on a feature branch and submit a pull request.
4. Run `./gradlew :app:testDebugUnitTest :app:assembleDebug` or rely on GitHub Actions checks.
5. For changes to the status-bar icon or notification, include on-device testing notes.

Never commit passwords, signing keys, keystores, tokens, or private data.

By contributing, you agree that your contribution is submitted under the project's [MIT License](LICENSE).
