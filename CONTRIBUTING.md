# Contributing

Thank you for your interest in NetSpeed!

1. Open an issue describing the bug or improvement, including device model and Android version when applicable.
2. Keep changes small and within the app's single-purpose scope.
3. Work in a branch and submit a pull request.
4. Run `./gradlew :app:testDebugUnitTest :app:assembleDebug`, or use the GitHub Actions checks.
5. Include on-device test notes or screenshots for icon and notification changes.

Never commit signing keys, keystores, tokens, or credentials.

**Licensing:** A public open-source license has not been chosen yet; please wait for the license to be added before submitting outside contributions.
